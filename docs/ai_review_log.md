# AI 활용 및 리뷰 기록

이 저장소는 AI가 작성한 참조 구현입니다. 학습자는 코드를 복사하는 데 그치지 않고 선택 이유와 검증 증거를 작성합니다.

## 구현에서 내린 선택

- 중복 충돌의 최신값을 추측하지 않고 모두 격리했습니다.
- 주문 상세 오류가 있으면 주문 전체를 제외합니다.
- 전체 스냅샷 게시로 계약을 명확히 하고, 사라진 키를 제거합니다.
- DW 반영과 성공 로그를 같은 트랜잭션에 넣고 실패 검증 기록은 ROLLBACK 후 보존합니다.
- 로컬 테스트와 실제 클라우드 검증 상태를 구분합니다.
