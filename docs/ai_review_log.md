# AI 활용 및 리뷰 기록

이 저장소는 AI가 작성한 참조 구현입니다. 학습자는 코드를 복사하는 데 그치지 않고 선택 이유와 검증 증거를 작성합니다.

## 구현에서 내린 선택

- 같은 키의 서로 다른 원본은 어느 쪽이 최신인지 추측하지 않고 모두 격리했습니다.
- 참조 오류는 버리지 않고 Unknown(-1)으로 적재한 뒤 표시했습니다. 매출에서는 빠지지만 "무엇이 왜 빠졌는지"를 MART에서 바로 조회할 수 있습니다.
- 매출 대상만 적재하던 구조 대신 모든 주문을 적재하고 `is_revenue_eligible` 플래그로 매출을 판정했습니다.
- 고객·상품은 SCD Type 2로 이력을 남겨 주문 당시 지역과 현재 지역을 모두 볼 수 있게 했습니다.
- 사라진 행은 물리 삭제 대신 소프트 삭제(`is_deleted`)로 표시했습니다.
- 노트북은 셀 단위로 실행되므로 MART 반영을 하나의 트랜잭션으로 묶지 않고, 품질 검사 결과로 실행 상태를 확정하는 게이트를 두었습니다.
- 같은 규칙을 SQL(노트북)과 Python에 모두 두고, 테스트와 행 단위 대조로 두 결과가 같은지 확인합니다.
- 로컬 테스트와 실제 클라우드 검증 상태를 구분해 기록합니다.
